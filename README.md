## Resumo
Este projeto consiste em uma API REST desenvolvida em C# utilizando Minimal API e Entity Framework, com o objetivo de gerenciar tarefas. O sistema permite o cadastro de usuários, categorias e tarefas, possibilitando a organização das atividades de forma estruturada e eficiente.

## Funcionalidades
- Cadastro de usuários
- Cadastro de categorias
- Criação de tarefas
- Listagem de tarefas
- Atualização de tarefas
- Remoção de tarefas

## Descrição das funcionalidades
O sistema permite que usuários criem tarefas associadas a categorias previamente cadastradas. Cada tarefa pode ser marcada como concluída ou pendente. Além disso, é possível listar todas as tarefas com seus respectivos usuários e categorias, atualizar informações e remover registros do banco de dados.
